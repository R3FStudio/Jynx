# Documentation

Jynx runs model-driven tasks from the terminal and exposes the same capabilities through a Rust harness and SDKs. Start with the quick start to use it, or the repository guide to change the code.

- [Models and runtimes](guides/models.md): local inference, API routes, native reasoning, and context.
