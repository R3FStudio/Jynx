# OpenAI-compatible integration

Connect an external tool to a compatible model endpoint by configuring its base URL, model identifier, and API key when required. Use the values supplied by the server you run; ports and authentication depend on that server's configuration.

See the [model guide](../../docs/guides/models.md) and [SDK reference](../../docs/reference/sdks.md) for Jynx-side connections. The harness JSON-line protocol and a model's HTTP API are different interfaces.
